Three editable `.docx` files come out, with PDF export on request.

| File | Audience | Contents |
| --- | --- | --- |
| Student Worksheet | Every student | Part A: Foundation + cut line + Part B: Core |
| Extension Challenge Card | Students who finish early | A standalone extension task card |
| Teacher Answer Key | Teacher only | Answers and explanations for all three tiers, writing mark scheme, tier-by-tier delivery notes |

**How the three tiers work** — they check **the same core learning**, not three different tests.
The difficulty differs only in how much support is provided, how complex the item formats are,
how much students have to write, and how deep the thinking goes.

| Tier | Character | Colour |
| --- | --- | --- |
| Foundation | Building the basics | Sage Green |
| Core | Checking understanding | Warm Orange |
| Extension | Going deeper | Terracotta |

**Assessment formats** — school written exams, extended-response and essay-style assessment,
performance assessment, the CSAT, mock exams, and external exams (IELTS, TOEFL, TOEIC, TEPS,
Cambridge). Tell the skill which one applies and it adjusts the marking criteria and item
formats. That adjustment changes only the assessment format; it does not override the base
design principles.

Where the lesson plan has no full reading passage, a new passage at the same topic and
difficulty is written and flagged as such.

### What to attach

- Lesson plan — required. The source of the topic, target vocabulary and grammar, activities and final task.
- Textbook content — required. The source material the questions are built from.
- Learner profile — optional. Grade, level, and how students split across the three tiers.

### What to type

> Make levelled worksheets for this lesson — it's for a performance assessment.

It does not stop to ask about the learners. Where the profile is missing it assumes from the lesson plan and the textbook, and states those assumptions in the output. Naming an exam type routes the tasks through that exam's item formats and marking criteria. Three editable `.docx` files come out, with PDF on request.
