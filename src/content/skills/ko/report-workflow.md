title: 학부모 안내문
tagline: 수업이 끝난 뒤 학부모에게 보낼 안내문을 A4 세로 이미지 한 장으로 만듭니다.
inputs:
  - 수업 지도안 (필수 — 주제, 어휘, 문법, 활동의 출처)
  - 교재 내용 (필수 — 어휘·예문의 정확한 근거)
  - 학급 정보 (선택 — 학급명, 날짜, 단원. 없으면 빈칸 표시로 남깁니다)
checks:
  - 4번 항목(학생 수업 참여 모습)이 비어 있는지 — AI가 대신 써 주지 않습니다
  - 교육학 용어가 남아 있지 않은지 ("스캐폴딩", "내재화" 같은 말은 학부모에게 쓰지 않습니다)
  - 어휘와 예문이 교재와 일치하는지
  - 글자가 깨지지 않았는지
---

A4 세로 한 장 분량의 **PNG 이미지**(요청 시 JPG)입니다. 가정통신문 발송 또는 기관 알림장
게시용으로 활용합니다.

| 항목 | 내용 |
| --- | --- |
| 1. 이번 수업에서 배운 것 | 학부모가 이해할 수 있는 말로 3문장 이내 |
| 2. 꼭 알아야 할 어휘 | 8~10개, 영어-한국어 대조 |
| 3. 문법 포인트 | 1~2개, 교재 예문과 함께 |
| 4. 학생 수업 참여 모습 | **비워 둡니다.** 교사가 손으로 적는 칸 |
| 5. 가정 학습 제안 | 집에서 할 수 있는 것 2~3가지 |
| 6. 다음 수업 예고 | 한 문장 |

**4번 항목은 반드시 비어 있어야 합니다.** 교사가 실제로 본 것을 손으로 적어야 의미가
있습니다. 나머지 항목은 학급 전체 단위 내용만 담으며, 학급명과 날짜 같은 정보가 없으면
빈칸 표시로 남깁니다. 예를 들어 `3학년 2반`, `10월 15일`처럼 학급 단위로만 적습니다.

**개인정보 처리 기준** — 이 스킬은 학생 실명, 학번, 개별 성적, 석차, 사진, 연락처를
안내문에 넣지 않습니다. 학급 전체 단위 내용만 작성합니다. 개인정보 보호법과 교육부 학교
개인정보 보호 지침에 따른 것입니다.

교사가 개별 정보 추가를 명시적으로 요청하더라도, 산출물 안내에 외부 발송 전 학교·기관의
개인정보 처리 방침 확인을 요구하는 경고가 함께 표시됩니다. 경고를 확인한 뒤 보내세요.
