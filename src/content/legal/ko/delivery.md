TeachFlow는 디지털 상품입니다. **실물 배송이 없으며**, 우편으로 발송되는 것은
아무것도 없습니다.

## 무엇을 받게 되나요

6개 스킬 전부를, **스킬마다 zip 하나씩 총 6개**로 받으시게 됩니다. 각 zip에는 스킬
파일과 참고 문서, 라이선스, 보안 고지가 들어 있습니다.

내려받으시는 zip에는 **실행 코드가 없습니다.** 안에 든 모든 파일은 실행 전에 열어서
읽어 보실 수 있는 텍스트 문서입니다.

## 파일을 받으시는 방법

호스팅 결제 페이지에서 결제하시면 결제 확인 즉시 결제 화면에 입력하신 이메일 주소로
다운로드 링크를 보내 드립니다. 저희가 보내 드린 청구서로 결제하신 경우에는 결제가
확인된 후 **영업일 기준 2일** 이내에 링크를 보내 드립니다. 도착하지 않았다면
<crossxtop@gmail.com> 으로 알려 주세요. 다시 보내 드리겠습니다.

다운로드 페이지에는 6개 스킬이 모두 표시됩니다. zip을 하나씩 내려받으실 수도 있고,
**전체 내려받기** 버튼으로 패키지 전부를 zip 하나로 받으실 수도 있습니다. 스킬의 새
버전이 나오면 같은 페이지에서 추가 비용 없이 받으실 수 있습니다.

## 실행에 필요한 것

- `SKILL.md` 형식을 읽는 코딩 에이전트 — Claude Code, Codex CLI, Cursor,
  Gemini CLI 모두 해당합니다
- 데스크톱 컴퓨터 (macOS 또는 Windows)
- 가르치실 단원의 교재 지면 — 쓰시는 에이전트가 읽을 수 있는 형태로

스킬은 전부 선생님의 컴퓨터에서 실행됩니다. **실행 중에는 인터넷 연결이 필요하지
않으며**, 입력하신 자료는 어디로도 전송되지 않습니다. 자세한 내용은
[보안 페이지](/ko/security)를 참고해 주세요.

패키지에 결함이 있다면 교체해 드리거나 환불해 드립니다.
[환불 정책](/ko/legal/refund)을 참고해 주세요.
