# TeachFlow 站点 UX 专业评估报告

**评估对象**：TeachFlow Skills 站点（Astro 静态站，`dist/` 构建产物，韩语 /ko 为主、英语 /en 对照）
**评估日期**：2026-09-21
**评估方法**：桌面端（1440px）与移动端（390px）全页面截图走查（/ko 首页、skills、samples、pricing、security、faq、install、buy + /en 首页）+ 关键源码审查（global.css、fonts.css、SiteHeader、SkillCard、SampleCard、PriceBlock、LanguageSwitcher、首页 hero）
**评估视角**：资深 UX 设计师，面向「韩国教师」这一核心用户群

---

## 一、总体判断（先说结论）

这是一座**工程质量极高、受众定位错位**的站点。

工程层面——零 JS 架构、自托管字体、WCAG 意识（aria-current、标题层级、reduced-motion、skip link、对比度实测记录）、韩文字号阶梯下调、合规页静音区——是我评审过的静态站里少见的严谨。安全页（/security）的 Agensi 安检矩阵是极佳的信任内容。

但设计语言的每一个信号——深空暗色底、终端辉光、等宽字体文件扩展名、命令行安装流程、USD 定价、邮箱下单——都在对访客说「这是给开发者的工具」，而买单的人是**韩国教师**。韩国教师日常接触的标杆产品（토스、Kakao、Classting、Riiid、아이스크림에듀）是明亮、亲和、大留白、强视觉证据的风格。当前的错位会直接压制转化率，与「专业、安全、提升教师效率」的品牌目标部分相悖。

**三个最优先动作（P0）**：

1. **修复韩文标题断词**——首页 H1「수업이 나 / 옵니다」在词中间断开，韩国用户一眼即觉「不专业」。全站缺 `word-break: keep-all`。
2. **打通购买死路**——主 CTA「가격 보기」→ pricing → buy，最终停在「직접 결제는 아직 열혀 있지 않습니다（直接支付尚未开放）」。转化漏斗的终点是一堵墙。
3. **韩国本地化信任三件套**——KRW（₩）定价、本土支付（KakaoPay / NaverPay / 토스페이）、KakaoTalk 客服频道。USD + Gmail 邮箱下单在韩国消费场景里近乎「不可信」信号。

## 二、分项评估

### 2.1 布局（Layout）— 评分 7.5 / 10

**做得好**
- `max-w-6xl` 居中容器 + 单一信息流，层级清晰：Hero → 流程图 → 六技能卡片 → 成品预览 → 隐私 → 价格 → 页脚，叙事顺序符合「认知→证据→信任→行动」的转化逻辑。
- FlowDiagram（여섯 스킬이 맞물리는 방식）是全站最有解释力的组件：输入（교재 단원 + 학습자 정보）→ 수업 지도안 → 四类产物，一眼讲清产品拓扑。移动端降级为纵向列表，取舍正确。
- 区块节奏统一（`py-12`），卡片网格 3×2 → 移动端单列，响应式行为稳定。

**问题**
- **[Major] /buy、/faq 等内容单薄页面没有视觉配重**：/buy 全页只有一个价格块 + 一段「支付未开放」说明，首屏大面积虚空，像「未完工页面」。转化路径上最关键的页面反而是信息量最低的。
- **[Minor] Hero 右侧 280px 的 HeroFan 视觉存在感弱**：截图中仅见一枚「한 단원」小芯片，没有承担起「首屏视觉钩子」的职责。首屏几乎是纯文字。
- **[Minor] 顶部导航 7 个条目 + 语言切换**，已达信息负荷上限；韩语标签短尚可容纳，但「설치 / Docs」对教师而言是行话入口，建议收纳。

### 2.2 主题与色彩（Theme）— 评分 6.5 / 10

**做得好**
- 色板纪律性强：`void/surface/raised/border` 四层深色阶 + 蓝（#2E7DFF）/青（#22D3EE）/紫（#A855F7）三 accents，且用「阶段色编码」（备课蓝 → 材料青 → 成果紫）赋予色彩语义，这是系统化的设计思维。
- 合规静音区（pricing/legal 取消辉光与动效）体现了对消费合规场景的细腻理解。
- 对比度有实测记录（text-mute on surface = 5.20:1，过 AA）。

**问题**
- **[Critical·定位层] 全暗色「开发者工具」基调与教师受众错位**。暗色 + 辉光 + 网格底纹是 Linear/Raycast 的语言，其受众是工程师。韩国教育科技的主流审美是亮色底、圆角卡片、柔和阴影、明确的品牌色块（参考 토스의 #0064FF on white、Classting 的明快插画）。建议：**至少提供亮色主题（韩国站应默认亮色）**，暗色可作为「开发者/代理用户」的备选。
- **[Major] 色彩情感单一**：全站只有蓝系冷色，缺少暖色锚点。教师场景的「关怀、成长」语义（韩国 edtech 常用珊瑚橙/暖黄做点缀）完全缺席，页面显得「冷、远、硬」。
- **[Minor] 主 CTA 的蓝（#2E7DFF）在深空底上明度对比中等**，首屏按钮的视觉权重不足以承担「全站唯一主行动」的角色。

### 2.3 图标（Icon）— 评分 7 / 10

**做得好**
- 单一 `ICON_PATHS` 来源、22px 统一尺寸、线性风格统一；h2 标题图标按语义着色（一览蓝 / 预览青 / 隐私紫 / 购买蓝），一致性好。
- 图标置于标题之外、不污染可访问名称——细节专业。

**问题**
- **[Major] 技能卡片图标抽象度太高、区分度低**：六张卡的图标都是「文档/窗口」类线性符号，扫读时无法形成「这张卡=幻灯片、那张卡=听力」的瞬间识别。教师是视觉化思维人群，建议换成更具象的教育隐喻（幻灯片→放映幕、听力→声波/耳机、词汇→表格/卡片、通知→信封）并放大至 28–32px。
- **[Minor] `.pptx / .mp3 / .xlsx` 等宽字体扩展名是图标语义的「第二语言」**——对开发者是精确，对教师是噪音。可保留但降为辅助信息（已是 text-xs，方向对），让图标与标题承担识别。

### 2.4 按钮与 CTA（Button）— 评分 6 / 10

**做得好**
- 主按钮（实心蓝 + 辉光 + hover 升起）/ 次按钮（描边）两级体系清晰；`px-5 py-3` ≈ 48px 高，触控目标达标；reduced-motion 下取消位移，细节到位。

**问题**
- **[Critical] CTA 漏斗终点是死路**：首页主 CTA「가격 보기」→ /pricing → /buy → 「직접 결제는 아직 열혀 있지 않습니다」。用户带着购买意图走到最后一步，得到的是「请发邮件」。在韩国电商语境（一键 결제 是默认预期）这等于放弃转化。**短期**：/buy 页放置 Agensi 购买按钮为主按钮 + 邮件为次路径；**中期**：接入本土支付。
- **[Major] 页面中段 CTA 退化为纯文字链接**（「무엇이 나오는지 보기」「직접 확인하는 방법」等只有 accent 色 + hover 下划线），在长页面中几乎不可发现。关键次行动应升级为「幽灵按钮」或带箭头图标加强 affordance。
- **[Major] 首屏 Hero 主 CTA 文案「가격 보기（看价格）」是过程导向而非价值导向**。韩国高转化 SaaS 首屏 CTA 多为结果导向：「묣로 결과물 확인하기（免费查看成品）」「샘플 받아보기」。把「看成品」升为主 CTA、「看价格」降为次 CTA 更符合决策心理（先建立价值感，再谈价格）。
- **[Minor] 页头缺少常驻 CTA**：滚动离开首屏后没有任何「行动出口」。建议页头右侧加小型主按钮。

### 2.5 弹窗与浮层（Modal / Overlay）— 评分 8 / 10（以「无弹窗」为有意策略评）

**做得好**
- 全站零 JS 策略下没有自建 modal：FAQ 用原生 `<details>` 手风琴、移动菜单用 `<details>/<summary>`——键盘可达、屏幕阅读器原生支持 expanded 状态，这是比 90% 的 JS 弹窗更正确的实现。
- SampleCard 有意用「缩略图直链原图新标签页」替代灯箱，并留有决策注释——取舍透明、可回溯。

**问题**
- **[Major] 原图新标签页 = 上下文丢失**：教师点开样张大图后离开站点语境，无说明、无下载按钮、无返回引导。建议用纯 CSS `:target` 灯箱（保持零 JS）或至少在新页加标题与「돌아가기」链接。
- **[Minor] 移动菜单 `<details>` 无外部点击关闭**：打开后点击页面空白处不收起（details 原生行为）。可接受，但与韩国用户习惯的 drawer 行为有差距。
- **[Minor] install 页没有「复制命令」按钮**（零 JS 的代价）——而 install 页恰恰面向最需要复制粘贴的非技术用户。这是「零 JS 教条」伤害核心用户的少数场景之一，建议为此页单独豁免，引入一个 `<script>` 复制按钮。

### 2.6 字体与排版（Typography）— 评分 8 / 10（韩文排印有亮点也有一处硬伤）

**做得好**
- **Pretendard 是韩文现代 UI 的最优解**（토스 同款），Inter + JetBrains Mono 搭配合理；全部自托管 woff2 + `font-display: swap` + unicode-range 子集——工程与隐私承诺（无第三方请求）兼得。
- 韩文整体字号阶梯下调一档（5xl→2.75rem 等）并改写 Tailwind token 而非选择器hack——这是真正懂「韩文同字号视觉更重」的处理，全站一致生效。

**问题**
- **[Critical] 缺 `word-break: keep-all`，韩文标题词中断行**：首页 H1「…수업이 나 / 옵니다.」把「나옵니다」从词中撕开。韩文虽允许任意断行，但词中断行在韩国用户眼里等同英文 "hel lo" 的破碎感，是「不专业」的强信号。修复：
  ```css
  html:lang(ko) h1, html:lang(ko) h2, html:lang(ko) h3 { word-break: keep-all; }
  /* 长 token（URL/文件名）兜底 */ html:lang(ko) { overflow-wrap: anywhere; }
  ```
- **[Major] 韩文标题继承了 `tracking-tight`（负字距）**：韩文是方块字，负字距会造成字面粘连，韩文排印惯例是 0 或微正字距。建议 `html:lang(ko) { letter-spacing: 0 }` 覆盖。
- **[Minor] 正文字号对中年教师偏小**：正文大量 text-sm（14px）+ 次要文字 text-xs。韩国教师主力年龄段 30–50 岁，建议正文基准 16px、辅助信息不低于 13px。
- **[Minor] 韩文行高 `leading-tight`（1.25）对多行韩文标题偏紧**，建议韩文标题 1.35–1.4。

### 2.7 文字量与信息密度（Copy Volume）— 评分 5.5 / 10

**问题**
- **[Critical] /skills 页是「文字墙」**：六个技能的完整 Markdown 说明顺序铺开，桌面端需滚动 3 屏以上的密集段落，无摘要、无锚点导航、无折叠。教师扫读 10 秒内找不到「这个技能给我什么文件」。建议：每技能卡首屏只保留「一句话价值 + 产物徽章 + 3 条要点 + 더 보기 展开」，详情折叠或独立子页。
- **[Major] /install 页同样过载**：四种 Agent（Claude Code / Codex / Gemini / Cursor）的命令行安装全文铺开。建议改为「选择你的工具」分步 Stepper（选项卡 → 对应步骤 → 验证检查清单），配合截图。
- **[Minor] FAQ 有一条不是问句**：「2022 개정 교육과정 성취기준 코드가 비어 있습니다（…是空的）」是陈述句，混在问句列表里显得像 bug 报告泄漏到了 FAQ。改写为问句形式。
- **[Minor] 首页各小节正文长度控制良好**（2–3 行一段），这是优点，保持。

### 2.8 图文配比（Visual : Text Ratio）— 评分 4.5 / 10（当前约 5 : 95）

**问题**
- **[Critical] 全站几乎零图像证据**：设计决策（spec §5.3）刻意用 CSS 辉光代替位图背景——作为「质感」成立，但作为「销售证据」缺位。教师购买决策的第一驱动力是「看到真实产出物长什么样」。当前 /samples 的 5 张预览图本身也是暗色文档截图，缩略图尺寸下不可读，且 3/5 标注「준비 중（准备中）」。
- **建议**：
  1. 把技能产出物（PPT 幻灯片、学习单、家长通知）渲染为**亮色、高分辨率、带设备/纸张 mockup** 的预览图，首页「실제로 나오는 결과물」小节直接内嵌 2–3 张，而不是只给一个链接；
  2. Hero 区加入「输入教材页 → 输出成品」的 before/after 视觉（HeroFan 升级）；
  3. 目标图文比拉到约 30:70——韩国高转化 edtech 落地页的常见区间。
- **[Minor] 纯 CSS 纹理（网格 + 辉光）执行克制、性能好**，若转亮色主题可保留为极浅底纹，不必推翻。

### 2.9 交互设计（Interaction）— 评分 7.5 / 10

**做得好**
- hover 升起、渐变描边、过渡曲线统一；`prefers-reduced-motion` 下零位移（且注释记录了「压时长≠零位移」的实测洞察）——动效治理是教科书级。
- 零 JS 仍保证全部核心功能可用（导航、FAQ、菜单、样张查看），健壮性极佳。
- 语言切换器 `hreflang` + `lang` 属性规范，`aria-current` 标注当前语言。

**问题**
- **[Major] 长页面缺少导航辅助**：/skills、/install 滚动深度大，无锚点目录、无返回顶部。建议加页面内 sticky 子导航（技能名锚点）。
- **[Major] 缺韩国本地客服触点**：韩国服务站的默认期望是 **KakaoTalk 채널** 悬浮按钮/页脚入口；当前只有 Gmail 邮箱 + 「2 个工作日内回复」。对韩国用户而言，没有 Kakao 频道 ≈ 没有客服。
- **[Minor] 表单类交互全缺**（无订阅、无询价表单），连「邮件通知我支付开放」的捕获入口都没有——/buy 的流量被完全浪费。
- **[Minor] 链接 hover 仅有颜色/下划线变化，焦点态依赖浏览器默认**：建议补全站统一的 `:focus-visible` 描边（已有表容器先例，推广到按钮与卡片）。

### 2.10 韩国审美与本地化契合（Korean Market Fit）— 评分 5 / 10

| 维度 | 现状 | 韩国市场期望 | 差距 |
|---|---|---|---|
| 主题明暗 | 全暗色开发者风 | 亮色、亲和、大留白（토스/Kakao 系） | 大 |
| 字体 | Pretendard ✅ | Pretendard ✅ | 无 |
| 断行 | 词中断行 ❌ | `keep-all` 按词断行 | 大 |
| 定价 | USD 29.90 | ₩39,900 式 KRW 整数定价 | 大 |
| 支付 | 邮箱询价 / Agensi | KakaoPay·NaverPay·토스페이 一键결제 | 大 |
| 客服 | Gmail | KakaoTalk 频道 + 域名为后缀的邮箱 | 中 |
| 主体信任 | 英国公司（CROSSXTOP LTD） | 사업자등록번호、통신판매업 신고 | 中（跨境销售可豁免，但需明示） |
| 内容证据 | 暗色缩略图、3/5 未就绪 | 明亮成品图、후기（评价）、学校案例 | 大 |
| 文案语体 | 平文体说明、准确自然 | 해요체/합쇼체 一致的敬语体系 | 小（整体地道） |

补充：韩语翻译质量本身是不错的（术语一致、语体统一），问题不在语言而在**商业与文化层**的本地化。

## 三、优势清单（务必保留的资产）

1. **零 JS 架构 + 全部核心功能可用**——性能、隐私、健壮性的三重资产，且与隐私承诺互为印证。
2. **/security 安检矩阵**——把「安全」从口号变成可逐项验证的表格（Prompt injection / Data exfiltration / Secret detection…），是 B2B 与学校采购场景的说服利器。
3. **自托管字体 + 无第三方请求**——隐私政策可验证，合规页静音区呼应，信任叙事自洽。
4. **动效治理与无障碍细节**——reduced-motion 零位移、标题层级契约（headingLevel prop）、aria-current、实测对比度记录。
5. **FlowDiagram**——全站最好的「一句话讲清产品」组件。
6. **韩文字号阶梯 + Pretendard**——韩文排印的地基是对的，只差 keep-all 与字距两处。

## 四、行动路线图

### P0 — 本周内（修复「不专业」信号 + 止血转化）
1. `html:lang(ko)` 加 `word-break: keep-all`（标题）+ 字距归零；全站截图回归确认无词中断行。
2. /buy 页：Agensi 购买按钮升级为主 CTA；加「결제 오픈 알림 받기（支付开放通知）」邮箱捕获；KRW 参考价并列展示。
