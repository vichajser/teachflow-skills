# KakaoTalk 客服频道接入方案（独立方案）

**版本**：v1.0 · 2026-09-21
**范围**：仅 KakaoTalk 客服频道（카카오톡 채널）的开通、运营与站点接入。不涉及定价、支付（按业主要求另行处理）。
**前提认知**：站点主体为英国公司（CROSSXTOP LTD），无韩国事业者登录证；全站零 JS、零第三方请求（隐私政策明确承诺，`tests/build/legal.test.mjs` 强制守卫）。

---

## 1. 为什么必须是 KakaoTalk 频道

- 韩国电商/服务站的客服默认形态是 **카카오톡 채널**（原 플러스친구）。韩国移动互联网 KakaoTalk 渗透率超过九成，教师群体（30–50 岁）尤甚——他们不一定每天查邮箱，但一定每天开 KakaoTalk。
- 当前站点唯一客服触点是 Gmail 邮箱 + 「영업일 기준 2일（2 个工作日）」承诺。在韩国用户心智里，「只能发邮件、还是 gmail」≈「没有客服 / 海外皮包公司」，直接压制付费转化与退款沟通体验。
- Kakao 频道还自带三个附赠价值：**채널 추가（关注）数是社会证明**、支持 1:1 채팅（会话式客服）、支持 자동응답（自动回复/常见问题机器人）。

## 2. 通道选型：先「免费频道」、后「비즈니스 채널」

| 形态 | 费用 | 韩国事业者登录证 | 能力 | 结论 |
|---|---|---|---|---|
| 카카오톡 채널（免费版） | 免费 | **不需要**，海外主体可开 | 1:1 聊天、自动回复、公告发帖、公开主页与链接 | **第一阶段采用** |
| 비즈니스 채널（认证版） | 免费（认证免费） | 需要韩国营业执照/法人登记 | 频道名旁认证徽章、搜索加权、알림톡（模板消息推送）资格 | **第二阶段**：等有韩国主体或经 Agensi 韩国渠道后再认证 |
| 알림톡 / 상담톡（付费消息/智能客服） | 按条计费 | 需要 비즈니스 채널 | 支付完成通知、下载链接推送、AI 客服 | 第三阶段，与韩国支付打通时一并上 |

关键判断：**不要等韩国主体**。免费频道今天就能开，先解决「有客服入口」的信任问题；认证徽章以后补。

## 3. 开通步骤（半天可完成）

1. 用 Kakao 账号登录 Kakao for Business（business.kakao.com），选择「카카오톡 채널 만들기」。
2. 频道名建议：**TeachFlow（티치플로우）**——韩英并记，教师搜索韩文也能命中。
3. 类目：교육/학습（教育）→ 語学/외국어。
4. 资料：头像用站点 favicon 同源的 TeachFlow 标识（方形 640×640）；封面图用首页 FlowDiagram 的亮色重制版（不要用暗色截图，Kakao 频道封面是品牌门面）。
5. 开启 **1:1 채팅**，设置营业时间（建议 평일 10:00–18:00 KST，与「2 个工作日回复」承诺对齐）。
6. 拿到两个关键资产：
   - 频道主页 URL：`https://pf.kakao.com/_xxxxxx`
   - 1:1 聊天直链：`https://pf.kakao.com/_xxxxxx/chat`

## 4. 自动回复内容设计（上线即配）

韩国教师的高频问题与 FAQ 高度重合，直接把 FAQ 前 6 条灌进 자동응답 키워드：

| 关键词 | 自动回复要点 |
|---|---|
| 가격 / 결제 | USD 29.90 一次性购买说明 + Agensi 链接 + 邮件直购路径 |
| 설치 | 指向 /ko/install（명령줄 없이 설치）|
| 환불 | 指向 /ko/legal/refund 摘要 + 邮件入口 |
| 학생 정보 / 보안 | 「학생 정보는 선생님 컴퓨터를 떠나지 않습니다」+ /ko/security 链接 |
| 샘플 | /ko/samples 链接 |
| 영수증 / 세금계산서 | 说明海外主体不可开韩国 세금계산서，可提供 Polar/Agensi 英文 invoice——**这条必须预先写好，是韩国 B2C/B2B2C 采购的最高频卡点** |

营业时间外自动应答：「영업 시간 외 문의는 순차 답변드립니다（평일 10:00–18:00 KST）」，与页脚承诺一致。

## 5. 站点接入方案（严守零 JS / 零第三方请求）

Kakao 官方插件（채널 추가 버튼 script、상담톡 위젯）都需要注入第三方 JS——**与本站隐私承诺和 no-js 测试直接冲突，禁用**。改用纯链接方案：

1. **页脚「고객 지원」区块**（`SiteFooter.astro`）：
   - 现有邮箱行上方加一行：「카카오톡 채널: @teachflow（평일 10:00–18:00 KST）」，链接到 pf.kakao.com 频道主页。
   - i18n：`footer.kakao`（ko: 카카오톡 채널 문의 / en: KakaoTalk channel (Korean support)）。
   - 英文页保留但标注 Korean support——英语用户主通道仍是邮件。
2. **自绘 Kakao 图标**：`src/data/icons.ts` 增加 `kakao` 键——手绘 talk-bubble 描边路径（与现有线性图标同一视觉语言），**不引官方品牌素材**，避免商标与外链问题。
3. **/pricing 的「문의와 지원」与 /buy 的「이메일로 문의」区块**：各加一行频道链接，作为邮件之外的第二触点。
4. **FAQ 页尾**：加一条固定条目「카카오톡으로 물어볼 수 있나요?」→ 频道链接。
5. **测试同步**：i18n 键 ko/en 必须同步添加（键集相等有测试守卫）；外链为纯 `<a href>`，不触发 no-js / 字体外链测试。

> 注意：`legal/privacy` 承诺「本站不向第三方服务器发请求」——纯 `<a href>` 链接点击后才跳转，不产生被动请求，承诺依然成立。这一点在改 privacy 文案时无需调整，但建议复核一次。

## 6. 运营 SOP

| 项 | 标准 |
|---|---|
| 首次响应 | 营业时间内 1 小时；非营业时间次日 10:00 前 |
| 语言 | 韩语优先，英语可转邮件 |
| 会话沉淀 | 每月把高频新问题回填到 FAQ 内容集合（src/content/faq）|
| 升级路径 | 技术问题（安装失败）→ 引导提供截图 → 必要时转邮件附日志 |
| 退款/合规 | 一律引导到邮件留痕（환불은 이메일로 접수），Kakao 只做指引不做承诺 |
| 隐私红线 | 教师可能在聊天里贴学生信息——自动回复里加一条「학생 실명·사진은 별도 동의 없이 본 채널에 별도 전송하지 마세요（请勿发送学生实名/照片）」 |
